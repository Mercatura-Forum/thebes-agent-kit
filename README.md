# Thebes agent kit

Everything an AI agent needs to build, deploy and run applications on
[Thebes](https://thebesprotocol.com): a map of the example applications, the
shared modules and the CLI, with the exact interface of every example contract.

- **[AGENTS.md](AGENTS.md)**: start here. Which example to start from, the deploy
  workflow, and the rules that matter.
- **[index.json](index.json)**: the machine-readable map
  ([schema](schema/index.schema.json)).
- **[interfaces/](interfaces/)**: the Candid interface of every example backend.
- **[llms.txt](llms.txt)**: the same map as a list of links.
- **[mcp/](mcp/)**: `thebes-mcp`, an MCP server with tools to find an example,
  start a project from it, check, deploy, upgrade and call contracts, and to
  sign in to Thebes Hosting, pay for a site and put it live.

## Use it with your agent

Claude Code:

```sh
claude mcp add thebes -- npx -y thebes-mcp
```

Any client that reads an `mcpServers` file (Claude Desktop, Cursor and others):

```json
{ "mcpServers": { "thebes": { "command": "npx", "args": ["-y", "thebes-mcp"] } } }
```

It needs Node 20 or later and the `thebes-deploy` CLI
([install](https://github.com/Mercatura-Forum/Thebes-Protocol-/releases/latest)).
An agent without MCP can read [AGENTS.md](AGENTS.md) and [llms.txt](llms.txt) directly.

## How the index stays true

`index.json` and `interfaces/` are generated by
[`tools/build-index.mjs`](tools/build-index.mjs) from the repositories listed in
[`sources.json`](sources.json), each pinned to a commit. Interfaces come from the
Motoko compiler (`moc --idl`); the modules an example uses come from its imports;
descriptions come from the hub catalog and [`catalog/platform.json`](catalog/platform.json).
`--check` rebuilds the index from scratch and fails if the committed copy differs.

```sh
node tools/build-index.mjs           # regenerate
node tools/build-index.mjs --check   # verify
```

Requires `git`, `mops` and `moc` 1.4.1.
